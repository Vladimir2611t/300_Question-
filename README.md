# Терапия: тренажёр

Офлайн-тренажёр для 295 тестовых вопросов по терапии: интервальные повторения, работа над ошибками, слабые темы, экзамен, статистика.

Открыть: https://vladimir2611t.github.io/300_Question-/

На Android: откройте ссылку в Chrome → меню ⋮ → «Добавить на главный экран». После первого открытия работает без интернета. Прогресс хранится на телефоне; резервную копию можно сохранить в «Статистике».

`questions.json` — вопросы, ответы и пояснения (`u: 1` — ключ неуверенный).
